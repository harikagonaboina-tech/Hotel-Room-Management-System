# Hotel Room Management System

This project is a **Java-based Hotel Room Management System** that allows administrators and staff to manage hotel room allocation, staff accounts, and guest details using **JDBC and MySQL database**.

---

## Technologies Used

* Java
* JDBC
* MySQL
* SQL
* Console-based application

---

## Features

### Admin Module

* Create staff accounts
* Update staff accounts
* Delete staff accounts
* View staff details

### Staff Module

* Staff login (Username/Password or OTP)
* Allocate rooms to guests
* Update room rent
* Find room details
* Deallocate rooms
* View all rooms

---

## Database

The project uses a MySQL database named:

```
hotel_management
```

Tables:

* users
* hotel_room

---

## How to Run

1. Create database in MySQL
2. Run the SQL script provided
3. Open the project in Java IDE
4. Run the file:

```
HotelRoomManagementSystem.java
```
